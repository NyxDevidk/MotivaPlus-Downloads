## Motiva Plus v0.1.0

Primeira versão pública para Windows e Android.

### Incluído

- acompanhamento de hábitos e metas;
- sessões de foco;
- progresso, XP, streaks e conquistas;
- área Anti-Luxúria com instruções de bloqueio no Android;
- interface responsiva para desktop e celular;
- barra de título personalizada no Windows.

### Arquivos

- **Windows x64:** `Motiva-Plus-0.1.0-Windows-x64.exe`
- **Android ARM64:** `MotivaPlus-0.1.0-Android-arm64.apk`

O APK utiliza uma assinatura de desenvolvimento para instalação direta. Uma futura publicação na Play Store precisará de uma chave de produção.
