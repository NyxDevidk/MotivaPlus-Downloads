# Motiva Plus

Aplicativo de produtividade para organizar hábitos, metas, sessões de foco e evolução pessoal em um só lugar.

## Downloads

Baixe a versão mais recente na página de [Releases](https://github.com/NyxDevidk/MotivaPlus-Downloads/releases/latest).

| Plataforma | Arquivo | Requisitos |
| --- | --- | --- |
| Windows | `Motiva-Plus-0.1.0-Windows-x64.exe` | Windows 10 ou 11, 64 bits |
| Android | `MotivaPlus-0.1.0-Android-arm64.apk` | Android em dispositivo ARM64 |

## Instalação no Windows

1. Baixe o instalador `.exe` na página de Releases.
2. Execute o arquivo e siga as etapas apresentadas.
3. Abra **Motiva Plus** pelo menu Iniciar ou pelo atalho criado pelo instalador.

## Instalação no Android

1. Baixe o arquivo `.apk` na página de Releases.
2. Autorize a instalação de aplicativos desta fonte quando o Android solicitar.
3. Abra o APK e toque em **Instalar**.

O APK atual é uma compilação ARM64 assinada para instalação direta e não é um pacote de publicação da Play Store.
